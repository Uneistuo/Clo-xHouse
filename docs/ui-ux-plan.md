## 2. 设计变量（Design Tokens）

**单一来源**：小程序在 `app.wxss` 顶层定义 CSS 变量 + `utils/theme.js` 导出同值常量；Web 在 `web/style.css` `:root` 定义同名变量。两端数值保持一致。

### 2.1 色板

```css
:root {
  /* 中性 */
  --bg-app: #f4f5f7; /* 页面底 */
  --bg-card: #ffffff; /* 卡片 */
  --bg-subtle: #f0f1f4; /* 分区/输入底 */
  --border: #e6e8ec;
  --border-strong: #d3d7de;

  /* 文字 */
  --text-1: #14161a; /* 主标题/正文 */
  --text-2: #5b616e; /* 次要 */
  --text-3: #9aa0ac; /* 弱化/占位 */

  /* 品牌主色（已锁定 A） */
  --primary: #e1483c;
  --primary-dark: #c5362c; /* 按下/hover */
  --primary-tint: #fdecea; /* 浅底/选中态 */

  /* 语义色 */
  --success: #16a34a;
  --warning: #f59e0b;
  --danger: #dc2626;
  --info: #2563eb;
}
```

### 2.2 订单状态 → 徽标

| status    | 语义色                            | 说明   |
| --------- | --------------------------------- | ------ |
| pending   | warning                           | 待收款 |
| paid      | success                           | 已收款 |
| done      | info                              | 待售后 |
| cancelled | neutral(`--bg-subtle`/`--text-3`) | 已取消 |
| refunded  | danger                            | 已售后 |

### 2.3 排版 / 间距 / 圆角 / 阴影

| Token           | 值                                                                |
| --------------- | ----------------------------------------------------------------- |
| 字体            | 系统字体栈；金额/统计用 `font-variant-numeric: tabular-nums`      |
| 主数字字重/字号 | 700 / 32–44rpx                                                    |
| 间距基准        | 4；小程序步进 8rpx：`8 / 16 / 24 / 32 / 40 / 48`                  |
| 圆角            | 卡片 24rpx、按钮 pill、输入 16rpx、弹窗 28rpx                     |
| 阴影            | `--shadow-1`(卡片) / `--shadow-2`(悬浮) / `--shadow-3`(弹窗) 三档 |

## 5. 全局交互规范（checklist）

- **Loading**：列表/详情优先**骨架屏**；弱网兜底转圈。
- **空态**：统一 `empty-state` 组件 + **主操作按钮**（如"去开单""新增商品"）。
- **反馈**：成功/错误/警告统一 toast + modal 规范；破坏性操作红色 + 二次确认（现状已较规范，统一视觉即可）。
- **刷新**：所有列表页开启**下拉刷新**（补齐 §1-O7 所列页面）；列表页统一上拉加载 + 骨架屏。
- **动效**：卡片轻进场、统计数字滚动；尊重 `prefers-reduced-motion`。
- **易用**：命中区域 ≥ 88rpx；对比度达标；最小字号 22rpx。
