常见问题

你可能想知道的

为什么 Web 端坚持零构建？

项目部署在 GitHub Pages，目标是推送即可发布。原生 ES Modules 与分层 CSS 足以支撑当前规模，省掉打包器、依赖升级与构建缓存，也让代码在浏览器里更透明。

开单时库存如何保证一致？

开单、取消与售后都在数据库事务中完成：先校验库存，再扣减 SKU，最后写入订单。任一步失败都会回滚；订单号唯一约束避免重复提交造成二次扣减。

小程序如何调用后端？

正式环境通过 wx.cloud.callContainer 走微信云托管，免服务器域名白名单；没有云开发环境时回退到 wx.request。请求失败按 1.5 / 3 / 6 / 10 秒指数退避重试。

展示页和原来的 Web 管理后台是什么关系？

当前 web/ 是项目展示页；原 Web 管理后台已完整归档在 archive/web-admin-v1.19.0/，需要恢复时把归档内容移回 web/ 即可。

如何部署？

展示页推送 master 后由 deploy-web.yml 自动发布到 GitHub Pages；后端推送后由 docker-image.yml 构建镜像，再部署到微信云托管。部署前记得配置 JWT_SECRET。
